How to Use

Input guide & variable glossary

NMR variables (lipidomics panel): enter raw values in mmol/L as reported by your NMR platform. No manual scaling needed.

Clinical variables (FPG, HbA1c, ALT, AST, CRP, HDL, LDL, height, BMI, age, sex): auto-standardised internally using training cohort parameters.

HbA1c must be entered in IFCC units (mmol/mol), not NGSP (%). To convert: mmol/mol = (% − 2.15) × 10.929

The coefficient tags (e.g. +0.58) indicate direction & strength of each variable's contribution to risk.

Missing fields default to cohort mean (equivalent to a z-score of 0 for scaled variables, 0 contribution for NMR variables with a coefficient applied to the actual value).

This tool is intended for research purposes only and does not constitute clinical advice. All predictions should be interpreted by a qualified clinician in the context of the full patient presentation.
